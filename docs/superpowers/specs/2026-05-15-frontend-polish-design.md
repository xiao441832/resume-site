# 全站前端美化设计

## 目标

把当前页面从“功能可用、样式偏基础”的状态提升为“完整、统一、适合毕业设计展示”的视觉体验。美化范围覆盖公开首页、个人公开简历页、普通用户后台和超级管理员后台，保持现有技术栈不变：HTML5、CSS3、Bootstrap 5、JavaScript、jQuery、Jinja2 服务端渲染。

本次设计采用“稳重专业型”作为整体方向，配色选择“深蓝 + 科技蓝”。页面应该显得清爽、可信、有系统感，尤其是后台要更像正式的网站管理平台，而不是简单表单页面。

## 设计原则

- 不引入 Vue、React、Angular，也不改成前后端分离。
- 允许引入 Bootstrap Icons CDN，用于菜单、按钮、状态和联系方式图标。
- 页面结构继续复用现有 Flask + Jinja2 模板。
- 重点提升视觉层级、间距、导航、卡片、表格、表单和移动端体验。
- 不做花哨营销页，不使用大面积渐变装饰和无意义装饰图。
- 后台以高效管理为主，前台以简历展示和访客浏览为主。

## 视觉语言

主色使用深蓝和科技蓝：

- 主背景：浅灰蓝，建议接近 `#f6f8fb`
- 主文字：深蓝黑，建议接近 `#152238`
- 主按钮和重点操作：科技蓝，建议接近 `#2563eb`
- 辅助成功色：绿色，建议接近 `#10b981`
- 边框和分隔线：浅灰蓝，建议接近 `#dce3ed`
- 卡片背景：白色

整体圆角控制在 8px 左右，阴影要轻，不做漂浮感很强的大阴影。按钮、表格、表单、状态徽章保持 Bootstrap 风格，但用统一变量覆盖成更精致的系统视觉。

## 公开首页

公开首页保留现有“公开简历列表 + 搜索”的核心功能，但加强首屏观感：

- 顶部导航更精致，品牌名、登录、注册入口层级清楚。
- 首屏标题聚焦系统价值，例如“多用户在线简历管理系统”。
- 搜索框作为主要操作区，使用卡片承载，输入框和按钮视觉更明显。
- 公开简历卡片显示头像、姓名、职业标题、城市、摘要和“查看简历”按钮。
- 卡片需要统一高度和稳定头像尺寸，避免内容多少导致布局跳动。

## 个人公开简历页

个人简历页要比当前更像一个正式在线简历：

- Hero 区突出姓名、职业标题、求职状态和简介。
- 头像或头像占位块更醒目，但不做夸张圆形大图。
- 联系方式使用图标 + 文本的形式，提高可读性。
- 技能区保留进度条，但进度条颜色和间距统一。
- 工作经历、项目经历、教育经历、证书继续分区展示，时间线和项目卡要更清晰。
- 留言表单保持在页面末尾，输入框、按钮和提示信息更整齐。

## 普通用户后台

普通用户后台继续服务于个人简历维护，不改变业务功能：

- 桌面端使用更明确的侧边栏，菜单项带图标。
- 移动端要避免侧边栏挤压内容，可以改为顶部折叠菜单或堆叠菜单。
- 仪表盘统计卡统一样式，数字更突出。
- 表格、表单、上传控件、保存按钮统一视觉。
- 当前页面标题、说明文字、主要按钮要形成清晰层级。

## 超级管理员后台

超级管理员后台要进一步强化“网站后台”的感觉：

- 使用平台管理菜单：控制台、用户管理、简历管理、留言管理、站点设置。
- 控制台统计卡使用更清晰的图标、数字和状态颜色。
- 用户管理、简历管理、留言管理表格要有更好的表头、状态徽章和操作按钮。
- 账号档案页保留当前功能，但布局更像管理后台详情页。
- 筛选区、快捷操作区和表格区域保持一致的卡片样式。

## 组件规范

需要统一以下组件：

- 导航栏：前台和后台风格区分，但颜色体系一致。
- 侧边栏：后台专用，深蓝底色，激活项使用科技蓝或浅蓝高亮。
- 卡片：统一边框、圆角、内边距和阴影。
- 按钮：主按钮、次按钮、危险按钮、链接按钮保持一致。
- 表格：表头背景、行间距、操作列按钮统一。
- 表单：标签、输入框、帮助文字、错误提示统一。
- 状态徽章：正常、封禁、禁止发布、未读、已处理使用固定颜色。
- 图标：使用 Bootstrap Icons，不手写图标。

## 响应式要求

- 手机端首屏标题不能过大，按钮允许换行。
- 简历卡片在手机端单列展示，桌面端多列展示。
- 后台表格在小屏幕使用横向滚动，不能挤压到文字重叠。
- 后台侧边栏在手机端不能占据过多高度，优先使用折叠菜单。
- 表单输入框和按钮在手机端要足够易点。

## 技术范围

预计主要修改：

- `app/static/css/main.css`
- `app/templates/base.html`
- `app/templates/public/index.html`
- `app/templates/public/resume.html`
- `app/templates/admin/layout.html`
- `app/templates/admin/dashboard.html`
- `app/templates/admin/users.html`
- `app/templates/admin/resumes.html`
- `app/templates/admin/user_detail.html`
- `app/templates/admin/messages.html`
- 其他后台资源列表和表单模板

不新增数据库表，不改变后端业务逻辑。仅在必要时为模板增加 CSS 类、图标元素和少量结构包装。

## 测试与验收

实现后需要验证：

- 本地 `pytest -v` 全部通过。
- `python -m compileall app` 通过。
- 桌面端和手机端页面无明显文字重叠。
- 公开首页、个人简历页、普通用户后台、超级管理员后台都能正常访问。
- 超级管理员后台仍然只显示平台管理菜单。
- 普通用户后台仍然只显示个人简历维护菜单。
- 表单提交、留言、后台保存功能不受影响。

## 不做的内容

- 不做 Vue、React 或前端打包。
- 不做新的业务功能。
- 不新增三层权限。
- 不新增主题切换。
- 不引入复杂动画。
- 不引入大尺寸图片素材作为主视觉。
